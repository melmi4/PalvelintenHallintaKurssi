# Sudo without password
- Jotta ansible saa pääkäyttäjän oikeuden se tarvitsee orjan avukseen. Tapa jolla tämä toteutuu on sallimalla sudo ilman salasanaa.
- Luodaan ryhmiä ja käyttäjiä komennoilla: sudo adduser, sudo groupadd sudoless, sudo adduser _ sudoless.
  
# xkcd
- Sarjakuvassa toinen hahmoista kieltäytyy tekemästä leipää ja kun siihen lisätään pyyntönä komento sudo hän alkaa tottelemaan.
- Tämä kertoo sudo komennon vahvuudesta
  
# Passwordless Sudo with Ansible
- Tämä on automatisoitu passwordless ryhmien ja käyttäjien luonti.
- Käyttäjille lisätään julkinen ssh avain ja kopioidaan sudoers säännön tiedostoon.
