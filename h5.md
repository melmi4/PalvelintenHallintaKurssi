## Chacon and Straub 2014: Pro Git, 2ed: 1.3 Getting Started - What is Git?

- Tiedot tallenetaan Gitiin spanshotteina eikä tiedostokohtaisina muutoslistoina ja jos tiedosto ei ole muuttunut, git ei tallenna sitä uudelleen, vaan se viitaa aikaisempiin samanlaisiin tiedostoihin.
- Melkein kaikki toiminnot ovat paikallisia ja committeja voi tehdä ilman verkkoyhteyttä.
- Git yleensä vain lisää tietoa. Committua tilannekuvaaa on vaikea kadottaa, jos tietokanta viedään säännöllisesti varastoon. Commitoittamattomat muutokset voi kuitenkin kadota.
- Tiedostolla on kolme tilaa: modified, staged ja committed.

## ' git add --all && git commit; git pull && git push '

- ' git add --all ' päivittää staging-alueen vastaamaan koko työhakemistoa. Uudeet, muutetut ja poistetut tiedostot merkitään seuraavaan committiin ' git-add '. 
- ' && ' ajaa komennon vain, jos edellinen oli onnistunut.
- ' git commit ' tallentaa sisällön uutena committina paikailliseen varastoon.
- ' ; ' ajaa seuraavan komennon riippumatta edellisen komennon tuloksesta.
- ' git pull ' hakee muutokset.
- ' && git push ' vie paikalliset commmitit etävarastoon, kuten githubiin.
